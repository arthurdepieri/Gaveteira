# Modelos Canva da Gaveteira

Arquivos importáveis no Canva:

- `gaveteira-card-template.svg`: modelo editável do card externo vertical.
- `gaveteira-ficha-interna-template.svg`: modelo editável da ficha interna.
- `gaveteira-card-template.png`: versão raster do card externo.
- `gaveteira-ficha-interna-template.png`: versão raster da ficha interna.

Parâmetros principais:

- Card externo: `342 x 520 px`.
- Capa externa: `342 x 220 px`.
- Ficha interna: `1120 x 900 px`.
- Capa interna: `220 x 292 px`.
- Raio visual base: `8 px`.

Uso:

1. Importe o SVG no Canva para editar camadas e textos.
2. Use PNG quando quiser uma referência visual travada.
3. Substitua a área `CAPA` por uma imagem exportada ou selecionada nas gavetas.
4. Mantenha status, nota, visibilidade e metadados como informação real da ficha.
